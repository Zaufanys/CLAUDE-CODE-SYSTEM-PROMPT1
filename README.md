# Cb-Grabber Project

A Python-based utility for credential and information gathering.

## Project Structure

```
.
├── Cb-Grabber/               # Main project directory
│   ├── CbGrabber.py          # Primary script
│   ├── requirements.txt       # Python dependencies
│   ├── README.md             # Project documentation
│   ├── LICENSE               # License file
│   └── images/               # Reference images
├── prompts/                  # Claude Code system prompt snapshots (reference)
├── CLAUDE.md                 # Project rules and guidelines
└── README.md                 # This file
```

## Getting Started

1. Install dependencies:
   ```bash
   cd Cb-Grabber
   pip install -r requirements.txt
   ```

2. Run the script:
   ```bash
   python CbGrabber.py
   ```
